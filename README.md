# 扫描全能王页脚水印去除工具

一个在浏览器中处理 PDF 的静态网页工具。选择文件、去除已识别的右下角扫描全能王标记，然后下载新 PDF。可以同时处理多个文件。

## 文件留在本机

- PDF 的读取、处理、预览和下载都在当前浏览器中完成，不上传到服务器。
- 不需要注册，不调用云端去水印服务，不需要 Python 或其他后端。
- 页面使用打包后的本地依赖，不从第三方 CDN 加载 PDF 处理代码。
- GitHub 仓库和网页可以公开；选择的文件不会因此公开，也不会保存进仓库。

浏览器仍需先从托管平台获取网页代码。请仅部署源代码和构建产物，不要将个人 PDF、处理结果或其他敏感文件提交到仓库。

## 支持范围

当前版本识别经过核验的扫描全能王页脚标记图像指纹，并检查其是否位于页面右下方：

- 删除独立的标记图片绘制操作，以及同位置的扫描全能王点击链接。
- 保留正文扫描图的原始图片数据和页面尺寸，不把整页截图后重新生成 PDF。
- 遇到不同版本的标记、已融入扫描图的水印，或无法可靠确认的内容时，跳过并提示。
- 加密 PDF 和包含数字签名的 PDF 会被拒绝处理。

这不是通用 AI 图片修复工具。如果水印已经与正文图像合并，尤其遮住了文字，本工具不会猜测或重绘被遮挡的内容。处理后请查看实际处理页数并检查预览。

## 本地运行

使用 Node.js 24 和 npm：

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。生成可发布文件：

```sh
npm run build
```

构建产物位于 `dist/`。项目使用相对资源路径，可以部署在域名根目录或子目录。

核心处理逻辑的合成样例测试：

```sh
npm test
```

测试与发布流程不应包含个人文件。真实文件的本机验证结果不属于公开测试样例。

## GitHub Pages 发布

目标仓库为 `huzhe01/camscanner-watermark-remover`，发布后地址为：

<https://huzhe01.github.io/camscanner-watermark-remover/>

1. 将本项目源码推送到仓库的 `main` 分支。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
3. 本项目的 `Deploy GitHub Pages` 工作流会安装锁定依赖、构建网页，并将 `dist/` 发布为 Pages 站点。

也可以在 Actions 页面手动运行工作流。工作流只构建网页，不读取或测试个人 PDF。发布成功与否以 GitHub Actions 的部署结果为准。

## 使用自己的服务器

无需改写处理逻辑。将 `dist/` 内的文件复制到静态网站目录，即可用 Nginx 等 Web 服务器提供服务。例如：

```nginx
server {
    listen 80;
    server_name pdf-tools.example.com;
    root /var/www/pdf-tools;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

对外部署时请为站点配置 HTTPS。PDF 处理依然在访问者浏览器中进行；服务器只提供网页文件，不需要文件上传接口。
